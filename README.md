# Hebrejská slovíčka – offline

Offline verze aplikace **Hebrejská slovíčka dle učebnice Anitšjerbeh pana docenta Mackerleho**.

Projekt automaticky vytváří:

- přenosnou aplikaci pro Windows 11 (`.exe`),
- instalační balíček pro Android (`.apk`).

Slovní zásoba se vloží do aplikace při sestavení. Hotové soubory jsou k dispozici v části **Releases**.
